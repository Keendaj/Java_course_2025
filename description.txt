Файл, полученный после сжатия, состоит из двух частей: заголовок и данные.

1. Заголовок

    Заголовок содержит информацию, необходимую для восстановления дерева Хаффмана и декодирования файла:
        originalLength — 8 байт (тип long)
        Длина исходного файла в байтах.

        totalBits — 8 байт (тип long)
        Общее количество битов в закодированном потоке данных.

        Словарь: таблица частот — 256 чисел типа int (4 байта каждое, всего 1024 байта)
        Каждое число соответствует частоте символа с кодом от 0 до 255.
        Например, freq[65] = 4 означает, что символ 'A' встречается 4 раза.

        Итого заголовок занимает 1040 байт.

2. Данные

    Данные — это поток битов, представляющий исходные символы по кодам Хаффмана:

        Каждый символ заменяется своим кодом Хаффмана.

        Последний байт может быть заполнен не полностью, поэтому для декодера важен параметр totalBits.
