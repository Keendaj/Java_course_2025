Добрый день!

Для online-сдачи практической работы (алгоритм кодирования-декодирования по методу Хаффмана) необходимо сделать следующее:

1. Предоставить ссылку на репозиторий, где будет находится
1.1. исходный код программы
1.2. инструкция по сборке (если требуется)
1.3. детальное описание структуры закодированного файла

2. Предоставить видео-материал, который будет содержать

2.1. обзор программы, т.е. открыть код в редакторе и рассказать о нем (показать основные части программы, рассказать зачем они нужны и как взаимодействуют друг с другом)

2.2. продемонстрировать работу программу на трех примерах:
    2.2.1. исходные данные: текстовый файл состоящих из 10 одинаковых символов. Например, "1111111111".
    2.2.2. исходные данные: текстовый файл длины 20 байт, состоящий из 3-х различных символов, каждый из которых встречается 10, 5 и 5 раз. Например, "11111111112222233333".
    2.2.2. исходные данные: бинарный файл, в который скомпилируется ваша программа, т.е. результирующий class-файл

2.3. демонстрация работы программы включает в себя:
    2.3.1. выполнение процедуры кодирования
    2.3.2. показ внутренней структуры получившегося файла
    2.3.3. рассказ об основные блоках элементов этой структуры
    2.3.4. осуществление декодирования
    2.3.5. сравнение результатов декодирования и исходных данных

Все сообщения писать мне на личный аккаунт.

Если есть вопросы - задавайте.
